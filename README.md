# Техническое задание: веб-приложение «Каталог книг»

## Зачем это вообще нужно

Книг много. Сервисов, где можно нормально их каталогизировать, отслеживать прочитанное и находить что-то новое — на удивление мало, особенно если не хочется платить подписку за Goodreads или мириться с его интерфейсом из 2009 года.

«Каталог книг» — это REST-бэкенд для личной и публичной библиотеки: можно добавлять книги с авторами, жанрами и издателями, оставлять отзывы, сохранять закладки со статусами «читаю / прочитал / хочу прочитать». Всё это с разграничением прав: обычный пользователь читает и взаимодействует, администратор управляет контентом.

Проект легко масштабируется до полноценного книжного сервиса или встраивается как бэкенд для мобильного приложения. А пока — хорошая база, которую не стыдно показать на GitHub.

---

## Сущности и их связи

Система строится вокруг семи основных сущностей.

**User** — пользователь системы. Хранит логин, захешированный пароль, email и роль (`ROLE_USER` или `ROLE_ADMIN`). Является точкой входа для аутентификации и связан с отзывами и закладками.

**Book** — книга. Основная сущность каталога. Содержит название и ISBN. Связана с жанром и издателем через `ManyToOne`, с авторами — через `ManyToMany` (одна книга может иметь несколько авторов, один автор — несколько книг).

**Author** — автор. Имя и биография. Связан с книгами через `ManyToMany`.

**Genre** — жанр. Просто уникальное название. Книги ссылаются на жанр.

**Publisher** — издательство. Название и адрес. Книги ссылаются на издательство.

**Review** — отзыв пользователя на книгу. Текст, оценка от 1 до 5, ссылки на книгу и пользователя.

**Bookmark** — закладка. Связывает пользователя с книгой и хранит статус: `TO_READ`, `READING`, `FAVORITE`.

## Что умеет система

### Работа с каталогом (публично доступно)
- Получить список всех книг
- Получить книгу по ID
- Получить список авторов, жанров, издательств
- Посмотреть отзывы к конкретной книге

### Действия авторизованного пользователя
- Зарегистрироваться и войти в систему
- Оставить отзыв на книгу
- Добавить книгу в закладки, изменить статус закладки, удалить её
- Посмотреть свои закладки, в том числе отфильтровать по статусу

### Действия администратора
- Полный CRUD для книг, авторов, жанров, издательств
- Просмотр списка всех пользователей

## Безопасность и авторизация

Аутентификация реализована через форму логина и HTTP Basic. Пароли хранятся в виде BCrypt-хеша. Сессии хранятся в базе данных через Spring Session JDBC.

Доступ к эндпоинтам разграничен по ролям:
- `GET /api/books/**` — открыт для всех
- `POST /api/users/register` — открыт для всех
- Запись в каталог (книги, авторы, жанры, издательства) — только `ROLE_ADMIN`
- Отзывы и закладки — только для авторизованных пользователей
- Список пользователей — только `ROLE_ADMIN`

## Качество и инфраструктура

**Тесты.** Проект покрыт unit-тестами (через Mockito) для сервисов и контроллеров, а также интеграционными тестами (MockMvc + H2 in-memory) для проверки реальных HTTP-запросов с учётом Security. Целевое покрытие — 70%, контролируется через JaCoCo.

**Логирование.** Все входящие HTTP-запросы логируются через `CommonsRequestLoggingFilter`. В сервисах используется `@Slf4j` с уровнями `DEBUG` / `INFO` / `WARN`. Логи пишутся как в консоль, так и в файл `logs/book-catalog.log`.

**Actuator.** Подключён и открыт полностью для мониторинга состояния приложения, метрик и логгеров.

**Миграции.** Схема базы данных управляется через Liquibase. На продакшн-окружении `ddl-auto=none` — Hibernate ничего не меняет сам.

## Структура API (основные эндпоинты)

```
GET    /api/books              — список книг
GET    /api/books/{id}         — книга по ID
POST   /api/books              — создать книгу [ADMIN]
PUT    /api/books/{id}         — обновить книгу [ADMIN]
DELETE /api/books/{id}         — удалить книгу [ADMIN]

GET    /api/authors            — список авторов
POST   /api/authors            — создать автора [ADMIN]
PUT    /api/authors/{id}       — обновить автора [ADMIN]
DELETE /api/authors/{id}       — удалить автора [ADMIN]

GET    /api/genres             — список жанров
POST   /api/genres             — создать жанр [ADMIN]

GET    /api/publishers         — список издательств
POST   /api/publishers         — создать издательство [ADMIN]

GET    /api/reviews/book/{id}  — отзывы к книге
POST   /api/reviews/book/{id}  — оставить отзыв [AUTH]
DELETE /api/reviews/{id}       — удалить отзыв [AUTH]

GET    /api/bookmarks          — мои закладки [AUTH]
POST   /api/bookmarks/book/{id}— добавить закладку [AUTH]
PUT    /api/bookmarks/{id}     — изменить статус [AUTH]
DELETE /api/bookmarks/{id}     — удалить закладку [AUTH]

POST   /api/users/register     — регистрация
GET    /api/users              — список пользователей [ADMIN]
```
